# Philis

Philis, The analog layout engine, allows the user to build circuits using
a simple API, and empowering the user with **Automated Place and Route** that
dumps the Python Code used to write it, along with the GDS.

See Docs for Usage:

1. View online: https://omarsiwy.github.io/Philis/
2. View locally:

```bash
python -m http.server -d docs
```
