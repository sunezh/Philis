Philis

The analog layout engine. Build circuits with a simple API and let Automated Place & Route emit the Python that wrote it, alongside the GDS.

Get Started API Reference

Simple API

Describe circuits declaratively in Python — no proprietary scripting, no GUI clicking.

Automated P&R

Placement and routing solved for you, with constraints you control when you need to.

Reproducible Output

Every layout dumps the exact Python used to build it, alongside a clean GDS file.

PDK Aware

Configured through technology files — ships ready for ciel PDKs such as sky130.

Quick Start

Install Philis and a PDK, then describe and route your first cell. 

pip install philis ciel
ciel enable --technology sky130
Tip: New here? The Getting Started guide walks through a full place-and-route example end to end.
