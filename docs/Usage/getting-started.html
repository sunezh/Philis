Getting Started

This is a placeholder page. Replace the body below with your real content — keep the <header>, <aside>, and <main> structure so the theme stays consistent.

1. Install

pip install philis ciel

2. Enable a technology

Philis is configured through a PDK technology file. ciel ships ready configurations: 

ciel enable --technology sky130

3. Build & route

import philis as ph

design = ph.Design("my_amp")
# ... describe your circuit ...
design.place_and_route()
design.write_gds("my_amp.gds")
