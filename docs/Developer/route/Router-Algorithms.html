Algorithms & Foundations

The problem setup invokes several mechanisms by name. This page derives each one from first principles and states precisely what it changes in the Philis formulation — which decision variable, cost term, feasibility predicate, or soundness argument it touches. Nothing here is a gate: these populate the soft tail, the search efficiency, and the evidence fidelity of an already-fixed feasibility structure.

Reading order. Engines 1–3 of the search-and-repair loop are: exact-local (§3, §9), negotiated congestion (§1), and maze A* (§7). The rest are priors, assignment oracles, data structures, and in-loop physics that feed those three.

1. Negotiated-congestion present/history cost

This is the routability backbone of engine 2 — an auction with memory. Each resource edge carries a cost 

cost(e) = (b(e) + h(e)) * p(e)

where b(e) is the base cost (the length/parasitic/via cost the oracles already attach via attr(e)), h(e) is history, and p(e) the present-sharing penalty: 

p(e)       = 1 + max(0, occ(e) - cap(e)) * p_fac
h^{i+1}(e) = h^i(e) + h_fac * max(0, occ(e) - cap(e))     (h_fac > 0)

occ(e) is the current occupancy, cap(e) the capacity (1 for an exclusive detailed edge, larger for a global tile). p_fac is raised across iterations so early passes explore freely and later passes forbid sharing. Because h(e) is monotone non-decreasing, a resource contested at iteration i stays expensive at i+1 — this is the convergence guard of the termination argument. The loop ends when no edge has occ(e) > cap(e) or a budget fires; overflow (occ(e) > cap(e)) is one of the marker sources that seeds scope(V).

2. Rectilinear Steiner trees (FLUTE / GeoSteiner)

Before detailed search commits tracks, each net needs a cheap, accurate two-dimensional topology prior and a wirelength lower bound. The rectilinear Steiner minimal tree (RSMT) connects pins with H/V wire of minimum length, possibly adding Steiner points. An optimal RSMT always has its Steiner points on the Hanan grid — the O(d²) lattice from drawing an H and V line through every pin.

FLUTE makes low-degree RSMT essentially free. For a net of degree d, encode only the pins' relative orderings (a "position sequence"). Within a class, an optimal RSMT's length is a fixed linear combination of the gaps between adjacent sorted coordinates: 

L = sum_i a_i * h_i  +  sum_j b_j * v_j

The finite set of optimal (a_i, b_j) vectors is the potentially-optimal-wirelength-vector (POWV) set; FLUTE precomputes POWVs + topologies for degree ≤ 9, so a net is a table lookup plus a dot product (optimal for d ≤ 9, ~1% off for larger after net-breaking). GeoSteiner is the exact branch-and-bound complement for the small, high-value nets where the 1% matters — a matched trunk, an RF symmetric tree, a power spine.

Maps onto Philis: (i) the global planner seeds each net with its FLUTE tree so congestion estimation sees realistic demand; (ii) Phi_pex gets an achievable-resistance floor per net, so a soft PEX outlier is distinguishable from an unavoidable one; (iii) matched/symmetric groups are planned as paired Steiner trees with a common template, giving the group invariant a geometric target. These are priors and bounds, never gates.

3. Integer multicommodity flow & LP rounding

This is the theory behind the route-state-invariant default. Treat each net as a commodity shipping one unit from a root to each selected access candidate. The fractional relaxation replaces x[n,e] ∈ {0,1} with x[n,e] ∈ [0,1] and solves an LP: minimize weighted edge usage subject to per-commodity flow conservation and sum_n flow(n,e) ≤ cap(e). This is polynomial and yields a fractional ("smeared") routing.

Randomized rounding turns it integral with a provable guarantee: interpret each net's fractional path weights as a probability distribution, pick one path per net independently, and the integral congestion exceeds optimal by at most an O(log|V| / log log|V|) factor w.h.p. (a Chernoff bound — each edge load is a sum of independent indicators concentrating around its fractional load).

Maps onto Philis: the global planner can solve the fractional LP on the coarse tile graph for a principled, congestion-balanced demand map and net order; the O(log/log log) bound is the formal answer to "how bad can congestion get" that the budget-bounded negotiated loop approximates. The exact ILP mode is the un-relaxed version, invoked only where integrality must be proved.

Matching as min-cost flow / optimal transport. The same machinery assigns paired/grouped terminals to access points so a matching objective (equal length, equal parasitic neighborhood, mirrored geometry) is met: cast the two halves of a group as a bipartite graph with edge cost = the imbalance that pairing incurs; the minimum-cost perfect matching (Hungarian / min-cost flow, optimal transport in the continuous limit) is the globally imbalance-minimizing pairing. It feeds engine 1 as an assignment oracle, leaving the group repair loop only the residual to equalize.

4. Pin-access oracle mechanics

A pin is a shape on one or more layers, not a point. The oracle enumerates access points (APs) — legal (layer, point, via-stack) triples — then chooses a DRC-clean, mutually compatible subset:

  1. for each pin shape, generate candidate APs on-track first (preferred-direction grid intersections inside the shape), then off-track and via-in-pin fallbacks;
  2. run the local rule oracle on each (enclosure, cut spacing, min-area, EOL, same-net notch) to keep only DRC-clean APs, attaching confidence and parasitic access cost;
  3. build an access-conflict graph (vertices = APs, edges = pairs that cannot coexist), precomputed once;
  4. select one AP per terminal with no two selected APs in conflict.

Step 4 is a small exact problem (independent-set / SAT selection) — which is why engine 1 owns it: a greedy per-pin choice can paint a later pin into an unroutable corner (the net-ordering pathology), whereas an incremental-SAT/ILP selection over the precomputed conflict graph finds a globally compatible set or proves none exists. The result is A_t with its ranking and a proof the chosen patterns are DRC-clean before any maze step — the precondition the incremental-DRC soundness argument assumes. For analog, each AP also records its symmetry/matching equivalence class (so the exact selection can pick mirrored APs for a differential pair) and each terminal exposes a multiport set across layers (so a current-carrying net can claim a via array, not a single stack).

5. Track assignment

Between coarse global routing and edge-by-edge detailed search sits track assignment: turn each net's per-tile global wire into a specific track for the long straight "trunk" segments, leaving only short jogs and pin connections to the detailed router. Per routing panel, collect the long wire segments (iroutes) that must cross it; the cost of assigning iroute i to track t combines its wrong-way extension, blockage overlaps, and — critically for analog — its coupling to adjacent occupied tracks. Assign all iroutes in a panel minimizing total cost (an interval-packing/assignment problem).

Maps onto Philis: two analog cost terms become first-class here. (i) Coupling-aware track choice: the adjacent-track coupling cost is exactly the Cc_window attribute and the gamma_nm·Cc term, so assigning a sensitive net to a quiet-neighbor track (or reserving the neighbor as a shield, sh[n,e]) reduces Phi_pex before detailed routing freezes it. (ii) Matched-group track symmetry: a differential pair or matched array is assigned to symmetric tracks about its axis in one joint step, the track-level realization of the group invariant. The payoff is clip-locality: detailed routing repairs short regions, not whole trunks.

6. Corner stitching

Every incremental DRC delta and local AP check asks the same low-level questions thousands of times: what shape is at this point, what shapes lie within this window, who are this tile's neighbors. Corner stitching makes these near-constant-time by tiling the whole plane — including empty space, as explicit maximal-horizontal-strip space tiles — with non-overlapping rectangles, each storing four "stitch" pointers at two opposite corners. From these it supports point finding (walk diagonally toward the query, cost ∝ local tile distance, not database size), neighbor enumeration (walk a tile edge via stitches), and area search (point-find then sweep). Insertion/deletion/stretching are local stitch surgery.

Maps onto Philis: it is the backing store that makes the bounded-influence incremental DRC cheap — an area search over the dilation of the changed region by r_max enumerates exactly the shapes whose legality could change, in time proportional to that region. The explicit space tiles let the access oracle ask "is there a legal empty landing pad here" without scanning all obstacles. It changes no decision variable; it makes clip-local verification affordable.

7. A* with landmarks (ALT)

Engine 3 is detailed A*/maze search, which needs an admissible heuristic to stay optimal and fast. Philis's edges carry non-Euclidean cost — via penalties, per-layer resistance, coupling windows, history surcharges — so Manhattan distance is either loose (slow) or, if scaled, inadmissible (wrong). ALT (A*, Landmarks, Triangle inequality) gives a provably admissible heuristic for any metric: pick a few landmark vertices, precompute exact distances to/from each, and lower-bound 

d(u,v) >= max_L | d(u,L) - d(v,L) |

Because it uses real graph distances (not an embedding) it is admissible on the actual cost graph including via/coupling costs, and it tightens A* exactly around blockages and dense channels where maze routing spends its budget. Landmarks are recomputed only on structural graph change and reused across a repair pass's many rip-up/reroute queries; bidirectional ALT halves the explored frontier on point-to-point pin connections. This changes no feasibility predicate — only how cheaply engine 3 finds the same legal minimum-cost path.

8. PEEC / RLGC and return-path reasoning

For RF/mm-wave and fast edges, a lumped R, Cg, Cc model is not enough — inductance and the return current path dominate. A segment is modeled per-unit-length by four parameters — series resistance R and inductance L, shunt conductance G and capacitance C (the RLGC model) — giving characteristic impedance 

Z_0 = sqrt( (R + jwL) / (G + jwC) )

which is why an RF transmission-line net constrains length, bend count, and a continuous reference plane, not just total wire. Current returns through the nearest low-impedance path; the loop the forward+return current encloses sets inductance and coupling, so a gap in the reference plane under a fast net spikes inductance and crosstalk. PEEC (Partial Element Equivalent Circuit) discretizes each conductor into cells and derives partial resistances, partial self/mutual inductances, and capacitive potential coefficients; "partial" means loop inductance emerges from summing partials around the closed forward/return loop — exactly what lets an in-loop extractor score a candidate route's inductive coupling and return-path quality incrementally.

Maps onto Philis: the EM_n/coupling terms of Phi_pex gain inductive-coupling and return-path-discontinuity components for RF nets; "continuous reference plane under the trunk" and "bounded bend count" become checkable bounded objectives (promotable to hard); shield insertion (sh[n,e]) is justified as return-path provisioning, not just capacitive screening. The certificate records the surrogate's delta to a signoff field solver where one exists.

9. Electromigration: Black's equation & the Blech length

Black's equation gives mean time to failure of a current-carrying segment:

MTTF = (A / J^n) * exp( E_a / (k_B * T) )

J is current density, n the current-density exponent (~1 when void growth dominates, ~2 when nucleation does), E_a the activation energy (larger for Cu than Al, so Cu BEOL tolerates higher J). MTTF falls steeply with J, so a segment carrying current I needs width/via-count such that J = I / (w·thickness) stays under J_max — this is EM-aware wire sizing, and EM_margin = J_max/J − 1 is the em_margin_min field of RouteQuality.

The Blech effect prevents needless over-sizing:

(J * L) < (J*L)_crit   =>   segment is "EM-immortal"

Below a critical current-density × length product, mechanical back-stress cancels the EM driving force and electromigration does not occur at all, so a short trunk can legally carry a density fatal in a long one.

Maps onto Philis: the width-class variable w[n,e,c] and via-array count are chosen so every segment is either Blech-immortal or has EM_margin ≥ 0 under Black's equation at the declared current; segments failing both are EM markers that seed scope(V) for re-sizing or re-topology, never silent acceptance. The promoting authority (PDK reliability rule vs. user current declaration) is recorded in the certificate.

10. Multipatterning conflict-graph coloring

On colored/multipatterned nodes, color assignment and decomposability are routing variables (col[n,e,p], mask[n,e,p], st[n,e]). Build a conflict graph: one vertex per feature on the multipatterned layer, an edge between two features whose spacing is below the single-mask minimum (they must go on different masks). Assigning masks is graph coloring, one color per mask:

  • Double patterning (2 masks) = 2-coloring, decidable in linear time by BFS; a graph is 2-colorable iff it has no odd cycle. An odd cycle no allowed stitch can break is a native conflict — a hard infeasibility geometry must change to resolve.
  • A stitch splits a feature into two touching pieces that may take different colors, breaking a cycle at a yield/overlay cost — so the real objective is minimize conflicts then stitches (an ILP / minimum-odd-cycle-cover).
  • Triple patterning (3 masks) = 3-coloring, NP-complete; solved exactly only on small clips, heuristically otherwise.

Maps onto Philis: the exact-engine assignment of col/mask/st is precisely this coloring/stitch-minimization ILP on the decision-dense clip — which is why advanced-node legality is a discrete problem the negotiated/maze engines cannot prove alone. A native conflict is its own diagnosis class and its own infeasibility core, never hidden as ordinary DRC. The linear-time 2-coloring check is cheap enough to run as an incremental delta on each commit.

11. Rubber-band / topological sketch routing

Analog routing benefits from reasoning about which side of an obstacle a wire passes — its homotopy class — before committing coordinates. Rubber-band sketch (RBS) represents each wire as an elastic band that, given a topological ordering of left/right obstacle passages, relaxes to its shortest realizable geometry. Two wires in the same homotopy class space and order freely; changing class means crossing an obstacle, a discrete decision.

Maps onto Philis: RBS is the global-topology representation for cases where the rigid track grid is too restrictive — symmetric and common-centroid escapes, RF trunks wanting gentle bends, matched pairs that must stay equidistant. Planning a matched pair as two rubber bands in mirrored homotopy classes gives the group invariant a topology-level target that is naturally symmetric before any track is chosen, reducing the residual skew detailed routing must equalize. It is the formal object behind "topology templates" in the case taxonomy; the rule oracle still proves the snapped result legal.

12. Honest framing of learning-guided routing

Learning-guided routers (generative-network or graph-neural-network guidance trained on expert analog layouts) predict where wires of each class are likely to go — a learned prior over routing regions and net ordering. The output biases the base cost b(e) of engine 2 and the net order of engines 1/3. The hard boundary: a learned prior may change which legal route is found first or preferred, but it can never relax a feasibility gate — DRC, LVS, connectivity, and promoted EM/IR gates remain rule- and extraction-proved. A miscalibrated prior on an unseen PDK can only slow convergence or worsen a soft score, never produce an unsound certificate, because every accepted edge still passes the exact oracles. This is the only safe way to admit ML into a signoff-first formulation, and it lives in the soft/ordering layer of the hierarchy, never in the hard vector.
